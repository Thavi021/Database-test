📦 Project Overview
This project is a simple full-stack web application that demonstrates how to connect a static frontend hosted on GitHub Pages to a cloud-based SQL database using Supabase.
The application allows users to:

Add messages to a database
Retrieve and display stored messages
Persist data across page reloads


🏗️ Architecture
The system uses a modern serverless architecture:
Frontend (GitHub Pages - HTML/JS)
        ↓
Supabase API (auto-generated REST interface)
        ↓
PostgreSQL Database (messages table)

Key Idea:
A static website communicates directly with a managed backend service (Supabase), eliminating the need for a custom server.

🧱 Implementation Steps
1. Database Setup (Supabase)

Created a Supabase project
Defined a messages table using SQL:

2. Security Configuration (RLS)

Enabled Row Level Security (RLS)
Created policies to allow public access:

SELECT (read)

3. Frontend Development
Built a simple UI with:

4. Supabase Integration
Connected the frontend to Supabase using the JavaScript client:
